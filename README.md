# Código-fonte e bibliotecas – Manual Arduino e Matemática

Este repositório reúne os códigos-fonte e as bibliotecas utilizadas no
produto educacional desenvolvido no âmbito do Mestrado Profissional,
voltado à integração entre Arduino, robótica educacional e ensino de Matemática.

## Objetivo

Disponibilizar, de forma organizada e acessível, os códigos e recursos
necessários para a reprodução das atividades propostas no manual,
favorecendo práticas pedagógicas baseadas na cultura maker,
na aprendizagem ativa e na contextualização matemática.

## Estrutura do repositório

- `/codigos/`  
  Contém os sketches Arduino correspondentes aos projetos e sensores
  apresentados no manual.

- `/biblioteca/`  
  Reúne bibliotecas externas utilizadas nos projetos que não estão
  disponíveis no Arduino Library Manager, sendo incluídas para garantir
  a reprodutibilidade das atividades.

## Observações

- Os códigos foram desenvolvidos para placas compatíveis com Arduino UNO.
- Recomenda-se a leitura do manual pedagógico para melhor compreensão
  das propostas didáticas e das conexões matemáticas envolvidas.
